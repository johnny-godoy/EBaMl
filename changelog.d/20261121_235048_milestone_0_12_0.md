### Changed

- Each page of the documentation has its own description and a title that names it, and the site loads the system fonts and no stylesheet from Google Fonts.
- The site no longer publishes the implementation plans of the milestones. `ROADMAP.md` links them on GitHub.

### Fixed

- The active link of the nav and the labels of the API reference have enough contrast for WCAG 2.2 AA in the light and the dark color scheme.
- A frame that holds the focus, such as an embedded notebook or paper, shows a focus ring, and the hidden "Back to top" button no longer takes the focus.
- The headings of the pages Setup, Usage and Choosing the model no longer skip a level.
- Each embedded paper has a link to its PDF next to the frame, for readers whose browser does not show the frame.
- The graph of income has a fixed size, so the home page does not move when the image loads.
