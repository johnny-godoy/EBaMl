### Added

- Importing `ebaml.llm.descriptors` runs `baml generate` when the generated `baml_sdk` package is missing. If that fails,
  the new `SDKUnavailableError` (also an `ImportError`) lists the steps that fix the cause: install the BAML
  toolchain, put it on `PATH`, or run `baml generate` in the checkout. It also shows the end of the command output.
