### Added

- `graph_png`, `graph_svg` and `graph_figure` draw the graph of a feature as an image: a step line with a confidence band for a continuous feature, bars with error bars for a categorical or boolean feature, and one series for each class of a multiclass classifier. `GraphImageOptions` sets the title, the score axis, the feature format and the confidence level. The image shows the same bins, scores and bounds as the graph text.
- The extra `vision` (`pip install "ebaml[vision]"`) installs matplotlib for the graph images. `MissingExtraError` names the extra when it is missing.
- `ModelKind.score_axis` names the score axis of a graph image for each model kind.
- `EBMGraph.series` splits the scores of a graph into one `GraphSeries` for each output, and `EBMGraph.resolve_format` gives the feature format that the text and the image present.
- `GraphOptions(mode=...)` chooses how each graph reaches the LLM in `describe_graph` and `describe_ebm`: `GraphMode.TEXT` (the default) sends the graph text, `GraphMode.VISION` sends an image of the graph, and `GraphMode.MIXED` sends the text with an image of the same simplified graph. The vision prompt asks the model to call each value that it reads from the image an estimate, and the mixed prompt takes every number from the text.
- `GraphOptions(vision_fallback=...)` chooses what a call in vision or mixed mode does when the model reads no images: `VisionFallback.RAISE` (the default) raises `VisionUnsupportedError`, and `VisionFallback.TEXT` sends the graphs as text and emits one `VisionFallbackWarning`. The first rejection decides for the whole call, and a rejected request is not retried.
- `ModelOptions(vision=False)` says that a model reads no images, so the fallback applies before any request.
- The BAML chain `describe_graph_cot` takes the PNG image of a graph in base64 (`png_base64`) next to the graph text, and the call needs the text, the image or both.
