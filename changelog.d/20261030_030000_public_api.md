### Added

- The package `ebaml` exports the public API: `describe_graph`, `describe_ebm`, `explain_instance`, `LocalExplanation`, `GraphOptions`, `PromptOptions`, `ModelOptions`, `compute_local_facts`, `facts_to_texts`, `LocalOptions`, `LocalFacts` and the result types of the local facts. Write `from ebaml import describe_ebm`. The functions that call an LLM load on first use, so `import ebaml` does not load the generated `baml_sdk`.
